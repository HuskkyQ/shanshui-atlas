# 山水志开发手册

## 景区页面规范

新增景区和现有景区改版以黄山与西湖总览页为基准。保留统一的界面层级和操作位置，按景区填写文案、视角、点位和路线。[黄山与西湖页面结构](../src/landscape/exhibit.html)

首页、景区总览和独立近景共用「湖青晨雾」与「砚墨朱砂」两套主题，默认使用湖青晨雾。页头切换后保存当前选择，加载界面、面板和画布随主题同步。界面用色使用 `--atlas-*` 公共变量。切换主题时保留当前镜头、模型材质和光影模式。[界面配色](../src/shared/theme.css) · [画布配色](../src/shared/scene-palette.js)

### 布局与内容

- **左上角**放「山水志」品牌和返回首页入口。**右上角**放「沉浸式体验／退出沉浸」。场景提供独立的光影模式时，在其左侧放「去除光影／恢复光影」。
- **左侧内容**按下方总览版式展示。选中景点时，切换为景点名称、可用照片、简述和资料链接，按需注明位置或复原范围。进入路线视角时，展示路线图例。
- **右侧探索列表**先列观察视角，再列景点。选中后，高亮条目、移动镜头并同步左侧详情。点位较多时，采用西湖的分类折叠方式。已具备独立近景模型的景点可提供「进入景点」。
- **右下角罗盘**随镜头转动，明确北向。有地理依据时使用地理北。采用建筑自身坐标时标注「模型方位」。
- **底部操作栏**依次显示左键旋转、Shift＋左键平移、滚轮缩放的提示，以及「自动漫游 ON/OFF」。手机端将探索视角移至底部，景点列表可横滑或折叠，操作提示可收为图标。

黄山以群峰全景、迎客松、云海和登山路线组织探索。西湖以湖山全景、湖畔、群山和步道组织探索，景点按上山口、山间名胜、湖畔名胜和西湖群山分类。新景区按自身内容设置视角与分类。[列表与景点详情联动](../src/landscape/exhibit.js)

### 左侧总览版式

以西湖总览为基准，以下五层共用左边线，由上到下排列。

1. **地区与坐标**使用金色小字和加宽字距。细横线起头，英文地区名与坐标之间用菱形分隔。坐标采用有依据的展示精度，无地理坐标的模型可填写区域或作品编号。
2. **中文景区名**使用象牙白宋体大字。短标题可让尾字错落，长名称按语义断行，保留清楚的主次关系。
3. **英文名**紧跟中文标题，使用金色小字、大写和加宽字距。
4. **景观短文案**使用易读的宋体，桌面以两行短句呈现，写出该景区的空间或景观特征。
5. **建模范围或依据**单独成行，字号和对比度低于短文案，说明所展示的范围、数据类型或复原依据。

桌面保留标题与正文之间的留白。手机按相同顺序缩放和换行，保证标题、英文名和说明在屏幕内可读。总览文案使用共用版式，模型、景点详情和路线图例按各自内容展示。[基准排版](../src/landscape/style.css) · [独立景区共用排版](../src/shared/exhibit-layout.css)

### 光影、沉浸与漫游

- **光影**由场景提供独立模式。目前黄山和西湖总览的「去除光影」切至中性照明和当前主题的灰阶背景，移除实时日夜、投影和雾效，收起文案、路线覆盖与点位。恢复时回到原照明和进入前的视角。采用固定展陈照明的页面省略此控件。
- **实时日夜**作为完整对齐黄山和西湖的单独验收项。按景区经纬度与当前时间计算日月方向和光照时段，底部显示北京时间。展陈补光随日照减弱而增强，保留地台、山脊和湖面的可读性。[日夜计算与展陈补光](../src/shared/lighting.js)
- **沉浸**沿用进入时的镜头，收起品牌、两侧文案和底部操作栏，保留罗盘及可交互的场景标记。点击标记可查看详情。沉浸期间暂停自动漫游，点击「退出沉浸」或按 Esc 恢复界面和选中状态。
- **漫游**在总览默认缓慢环绕。手动拖动时让出镜头控制，松手或滚轮缩放结束后从当前视角立即继续。镜头过渡、需要静止的路线或近景、去除光影、沉浸及第一人称行走期间暂停。用户主动切到 OFF 后，继续保持关闭直至手动开启。遵循系统减少动态效果设置。
- **单侧景区**按主要建筑的可见方向设置往返范围。大慈岩在建筑正面左右各 24° 内自动往返。手动转到范围外时暂停，回到范围内且漫游为 ON 时继续。

独立景区优先复用公共展览控件、布局、漫游与罗盘模块，再接入本场景的镜头和点位状态。[公共展览控件](../src/shared/exhibit-controls.js) · [公共布局](../src/shared/exhibit-layout.css) · [自动漫游](../src/shared/auto-roam.js) · [罗盘](../src/shared/compass.js)

### 来源展示

首页景区卡片提供独立的「数据来源」入口，列出整体模型依据、可核验链接和近似范围。单个景点的照片、引用和点位说明放在模型页的详情内。首页封面使用模型画面，隐藏场景中的景点标记。

### 验收清单

- [ ] 用桌面 1280×720 和手机 390×844 对照黄山、西湖的布局，检查左侧五层内容的顺序、标题换行、两侧内容与罗盘和操作栏的避让。
- [ ] 从探索列表和场景标记分别选择景点，检查镜头、选中状态、左侧详情和来源链接是否对应。具备路线视角时检查左侧图例。
- [ ] 对有独立光影模式的页面，从近景切换去除光影与恢复光影，检查背景、照明和视角。固定展陈照明的页面检查按钮是否省略。要求实时日夜的页面另核对日间与夜间效果及底部时段。
- [ ] 在首页、总览及独立近景切换主题，检查界面和画布同步，并从刷新与跨页导航确认选色保留。
- [ ] 检查沉浸模式的进入、热点查看、退出按钮和 Esc，以及返回后的选择和界面状态。
- [ ] 在总览中拖动、滚轮放大与缩小，确认停止操作后下一帧继续漫游。手动关闭后再操作，确认仍为 OFF。
- [ ] 从首页打开数据来源，核对来源入口、覆盖范围和可核验链接。进入景区时确认封面与场景内容对应。
