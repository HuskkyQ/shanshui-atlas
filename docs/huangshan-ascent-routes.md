# 黄山上山路线研究笔记

核验日期：2026-09-30。用途：为 Three.js 展示绘制“从登山口进入核心景区”的示意轨迹。路线名称和节点有官方依据；下列线条仍应视为模型近似，不是导航数据。

## 可用于模型的四条主线

| 登山口 | 可确认的步道方向与主要节点 | 索道关系 | 建模建议 |
|---|---|---|---|
| 慈光阁（前山、南门） | 慈光阁 → 半山寺 → 天都峰脚/天都新道口 → 玉屏楼；官方玉屏景区介绍明确了“慈光阁经半山寺、天都峰脚至玉屏”。官方古道资料还把慈光阁归入“温泉至玉屏古道”。 | 玉屏索道下站在慈光阁附近、上站到玉屏；索道不能替代步道几何。 | 沿已连通的公开步道绘制主线，并用半山寺、玉屏楼等节点校验。 |
| 云谷寺（后山、南门） | 云谷寺 → 白鹅岭 → 北海/始信峰方向。官方古道资料列出“云谷寺至北海古道”，官方 2025 公告确认“云谷寺至白鹅岭游步道”开放。 | 云谷索道连接云谷寺与白鹅岭；模型应与步道分开。 | 沿已连通的公开步道绘制主线，并用白鹅岭、北海等节点校验。 |
| 松谷庵（北门） | 松谷庵 → 二龙桥/北海方向；官方古道资料将其列在“二龙桥至北海古道”沿线，并列出松谷亭、乌龙亭、刘门亭等节点。官方 2024 公告明确“松谷庵—北海登山游步道”。 | 太平索道下站邻近松谷庵、上站至松林峰；它是索道线，不是步道。 | 沿已连通的公开步道绘制主线，并用松谷庵、北海等节点校验。 |
| 钓桥庵/吊桥庵（西门） | 官方景区概况把钓桥景区定为以钓桥庵为中心，位于黄山西部；官方文章说明正式称呼为“吊桥庵”，俗写“钓桥庵”。《总体规划》表 9-20 的西面生态四日游第一天明确列出：钓桥庵景点 → 三溪口 → 步仙桥 → 梦幻游览区南行 → 天海。该规划路线可作为西侧主线的节点顺序，但属于 2007—2025 规划方案，不代表 2026 年实时开放。 | 未找到与钓桥庵相连的现行客运索道；不要把西海大峡谷观光缆车当作钓桥庵上山索道。 | 可绘制“钓桥庵 → 三溪口 → 步仙桥 → 梦幻游览区南侧 → 天海”示意线；把线路标记为规划/低置信度，待实时开放公告或现场轨迹校正。 |

官方将黄山登山古道概括为以天海为中心的东、西、南、北四条主干道，辅以支道，历史主干道约 40 km；现有全山磴道约 85 km。因此模型可把四个登山口视为四条主入口，再在山顶用北海、天海、玉屏、西海节点连接，而不应把四条线画成互不相交的独立路径。

## 山顶联络段（2026-09-30 修正）

初版只提取入口至玉屏楼、天海或北海的四段线路，导致前山和西线在视觉上成为断头路。现按官方[玉屏景区资料](https://hsgwh.huangshan.gov.cn/zjhs/ldjq/ypjq/8665906.html)及[登山古道资料](https://hsgwh.huangshan.gov.cn/zjhs/hsws/gd/9237971.html)补充玉屏楼—百步云梯—鳌鱼洞—天海，以及天海—光明顶—北海两段。后者的游览顺序也可由[总体规划的南上北下线路](https://hsgwh.huangshan.gov.cn/group1/M00/02/7D/wKgoC1_Auv-AODLOAB0M_MT9Cmo498.pdf)交叉核对。OSM 主连通图中的两段分别约 1.85 km 和 1.84 km，端点与四条入口线共用同一 OSM 节点。其台阶仅作视觉表达，不对应真实级数。

## 索道与步道必须分层

- 慈光阁—玉屏为玉屏索道；云谷寺—白鹅岭为云谷索道；松谷庵—松林峰为太平索道。官方规划附录明确这三条索道的现状端点。
- 官方换乘信息把慈光阁称为“步行登山口”，并说明南门换乘后到云谷寺、慈光阁；慈光阁方向步行游客还需从桃花峰换乘站转免费摆渡车。
- 本次四条徒步线没有包含东大门；东门和索道的通行方式需另据景区最新公告核验。

## 开放限制（用于界面提示，不写死为永久状态）

- 官方常规运营公告要求徒步登山检票口 15:00 关闭，之后“只出不进”；预约、限量、错峰和分方向实名核验持续执行。该类时间会按季节和节假日调整。
- 天都峰、莲花峰实行轮休和临时封闭机制；天都峰还需实名预约，恶劣天气可临时关闭。模型可以保留天都峰节点，但不要把它标为始终可通行。
- 官方 2025-03-18 公告曾说明西海大峡谷、西大门和云谷寺—白鹅岭恢复开放，同时慈光阁—玉屏楼步道因修缮临时关闭；这证明路线状态会因维护变化。官方 2026 年网站首页已出现“黄山西海大峡谷恢复开放（2026-03-14）”等新公告，但本次未能读取对应公告正文，不能据此推断 2026-09-30 的每条步道状态。
- 钓桥庵、西海大峡谷、松谷庵等西、北侧路线尤其不应根据旧攻略或 2007—2025 总体规划判断当前开放；上线时应链接景区实时公告或“智游黄山”。

## OSM 数据边界

已从 OSM 主 API `/api/0.6/map` 获取整个模型 bbox 的 XML，并统计到 147 条 `steps`、63 条 `footway`、46 条 `path`；这些要素可以形成用于绘制的主连通图。OSM 几何解决了“没有线”的问题，但仍不能单独证明每条线就是景区官方游客步道，也不能证明当前开放。

可确认的是，公开 OSM 衍生页面能找到慈光阁建筑、慈光阁索道站、云谷新索道站、北大门游客中心等点/面要素，例如 [慈光阁](https://mapcarta.com/W137223201)、[慈光阁索道站](https://mapcarta.com/W137223206)、[云谷新索道站](https://mapcarta.com/W214865667)。这些页面明确标注数据来自 OpenStreetMap，但它们只证明局部 POI/建筑存在，不能证明四条徒步线路连续、方向正确或代表当前开放状态。

当前实现从 OSM 几何中抽取 `highway=path/footway/steps/pedestrian`，按节点连通关系选取主连通图，并依次经过官方资料所述的关键节点，再贴合 DEM 高程。普通道路、明确禁止通行的步道和孤立线段不参与寻路。钓桥庵线用表 9-20 的“三溪口—步仙桥—天海”顺序校验，但仍只称为公开地图几何，不冒充实时官方游线。
