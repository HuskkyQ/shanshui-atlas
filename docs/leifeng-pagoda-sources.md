# 雷峰塔独立场景资料与模型边界

核验日期：2026-10-15。本轮表现现代重建塔，以原创程序化几何制作，不使用下载的第三方模型或照片纹理。

## 资料

- [杭州网 · 宋韵迹忆：带你了解杭州雷峰塔](https://z.hangzhou.com.cn/2022/syjy/content/content_8421276.html)：现代重建塔的楼阁形制、铜制外檐构件、古塔遗址保护罩以及夕照山和雷峰夕照的景观关系。配图用于人工核对外观，不复制进项目。
- [中国国家博物馆：展览解读 · 什么！它们竟是铜做的？](https://www.chnmuseum.cn/zl/zlxw/202409/t20240918_270155.shtml)：2002 年新塔、钢架与铜制屋瓦/脊/柱/栏杆，以及铜斗拱的实物与工艺资料。
- [杭州市文广旅游局：雷峰夕照](https://wgly.hangzhou.gov.cn/art/2022/12/1/art_1229696389_58943150.html)：沿用 World 信息卡的景区来源。页面的“五面八层”表述与其他中文资料及外观不一致，本模型采用五层八面的外轮廓，不依据这一倒置表述建模。

## 本轮范围

模型展示八角五层主楼、逐层收分的飞檐、深色铜瓦与屋脊、窗格、斗拱、栏杆、塔刹、现代台基与宽阶梯，配少量植被和近景步道。四个热点为塔身、塔基与遗址、铜檐与斗拱、西湖远眺；介绍独立保存于 `src/content/leifeng-pagoda.json`，每条附可追溯来源。

2026-10-13 根据用户提供的现代塔正面照片重审外观：底层屋檐加宽，上部四层压缩层高并逐层收分；顶层使用独立的七段八角攒尖曲面，瓦脊和细瓦线共用屋面采样，避免脊条悬浮。立面改为浅色围护、暗红铜柱和窄拱窗，窗户沿八角墙面的法向贴合；檐廊增加外挑平台和灰色栏杆。塔刹由金色底座、九组叠盘、长杆、圆形饰件和尖饰组成，细支索连接实际冠顶檐角。叠盘数量、窗型细节和比例来自照片的视觉近似，并非实测构件清单。

近景与西湖总览共用塔体、台基、屋顶及平台几何和材质，总览统一按 `.005` 缩放，塔高约 35.1 个局部展陈单位，映射为约 0.1755 个 World 单位。局部单位按 0.5 展陈单位／米换算，塔体高度约 70 米；源 OSM 塔区轮廓约 58×56 米。上述比例用于展示构图，模型仍是艺术近似，不是测绘成果。首帧总览沿用飞入景点时的投影视角。

建筑尺寸、构件比例、台阶级数与周边环境为艺术化近似。没有施工图或摄影测量数据；没有复原地下遗址、保护罩内部、楼内展陈或电梯。台基热点介绍遗址保护背景，画面只显示现代台基外部；历史亭阁不猜测落位。

近景坐标是独立展陈坐标，不用于新增地图点位。背景湖面在对应源湖面标高上作为展陈背景，不宣称为雷峰塔处的精确视域；不额外绘制假远山。使用固定展陈日光，色温稍作中性调整以呈现深灰屋瓦与浅色墙面；World 仍沿用实时太阳/月亮光照。

## 2026-10-15 景区布局改造记录

- `src/west-lake/leifeng-pagoda/site-layout.js` 由 `scripts/generate-leifeng-site.py` 根据离线 OSM 原始快照和现有项目 DEM 生成。数据保留 WGS84 来源信息、园区边界、池塘轮廓、入口／出口／山顶节点、十段裁切后的步道，以及局部高程网格。
- 景区布局使用源 park polygon、放生池 polygon 和裁切后的 walk／ascending 路线；入口只表现为小型开敞坪和窄步道，没有凭空添加无资料依据的门楼形制。
- World 继续使用已有地形，只在塔基、入口和池塘附近做局部 grade；共享核心不会复制整块单景山体。Scenic 使用闭合的自然 hill，保证低角度观察时有侧壁和底面。
- 塔区局部平台在半径约 31 米范围内做平整，并在 31–60 米范围内渐接原有地形，避免原生 4 倍 DEM 高程形成高挡墙。池塘岸地也只做局部平整。
- 雷峰塔保护性建筑保留外部 base 表现，内部遗址不复原。World 使用 `.005` 统一缩放，避免改变共享塔体比例；具体地图接地仍以现有 DEM 和局部展示修正为准。
