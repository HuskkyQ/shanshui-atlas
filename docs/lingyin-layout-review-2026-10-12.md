# 灵隐寺布局复核（2026-10-12）

本轮针对用户提供的斜视航拍标注图复核现状布局，并对照灵隐寺官网交互导览、官网建筑文章、官方日文导览、现有调查文档和 `src/data/lingyin-layout.json`。航拍图是透视图，标注位置不能直接换算为 WGS84、米制长宽、台阶高差或建筑朝向；复核用图已保存为[航拍参考图](./lingyin-aerial-review-reference.png)。

## 先给结论

1. 航拍图显示的“入口近端 → 天王殿 → 上香区 → 大雄宝殿 → 观音殿 → 药师殿 → 藏经阁 → 华严殿”可以作为**视觉核对线索**，但与灵隐寺官网稳定使用的现状中轴名称不完全相同。官网现状中轴是“天王殿 → 大雄宝殿 → 药师殿 → 直指堂（法堂） → 华严殿”；官网交互导览进一步说明第四进同一建筑由顶层藏经楼、中层法堂、底层文物展厅组成。
2. “观音殿”不能据航拍标签直接插入成独立主轴建筑。灵隐寺官网明确描述大雄宝殿背后有大型海岛观音/五十三参群雕；这足以解释观音在大雄宝殿背面的视觉存在，但尚未证明航拍标签对应一个独立、位于大雄与药师之间的观音殿外廓。
3. 当前 `src/data/lingyin-layout.json` 的 `zhizhi` 继续使用 `way/434366739`，并保留 OSM 原名“灵隐寺文物展厅”，同时用 `sourceName`/`semanticRole` 表达项目的“直指堂／藏经楼”语义。它与官网导览核验的第四进三层功能体对应；OSM 外廓仍只应称为底层展厅候选外廓，不能把 OSM 名称改写成已测绘的整座直指堂名称。
4. 航拍图左侧标签读作“月恒堂”，不是“明恒堂”。灵隐寺官网 2015 年公告和 2021 年水陆法会文章都使用“月恒堂”；右侧“十方苑、客堂、伽蓝殿、济公殿”也在官网活动/开放文字中出现，但目前没有找到带 WGS84 坐标的官方总平面公开数据来验证航拍像素相对位置。
5. 大雄宝殿“三重歇山/三道檐线”、药师殿“单层重檐歇山”、五百罗汉堂“卍字形、双檐反翘”有官方一手文字支持。天王殿具体檐数、华严殿具体檐层，当前官方资料仍不足以据航拍像素确定。

## 证据分级

### 已由官方文字或官方导览核实

- 灵隐寺官网现状介绍：中轴主体为天王殿、大雄宝殿、药师殿、直指堂（法堂）、华严殿；两侧附五百罗汉堂、济公殿、联灯阁、华严阁、大悲楼、方丈室等。
- 官网交互导览图的“直指堂（法堂）”弹窗：第四进为同一建筑的三层功能关系，顶层藏经楼、中层法堂、底层文物展厅。
- 官网《千年古寺 大慈灵隐》：大雄宝殿后壁为大型海岛观音/五十三参群雕；药师殿是第三重殿，单层重檐歇山顶、面阔七间、进深三间。
- 同文：大雄宝殿为仿唐建筑，单层三重歇山顶，面阔七间、进深四间，高 33.6 米。这里的“单层殿身”和“三重檐线”必须分开理解。
- 灵隐寺官方日文导览：五百罗汉堂位于大雄宝殿西侧，卍字形、总面积 3116 平方米、中央高度 25 米、清代仿建筑双檐与反翘檐口；药师殿在大雄宝殿后、1993 年重建、二重檐入母屋/歇山语境、七间×三间。
- 灵隐寺官方英文/中文钟鼓楼资料：钟楼、鼓楼位于天王殿两侧，鼓楼在西、钟楼在东；这可用于修正“钟鼓楼待定”的模型规划，但资料没有提供可直接复用的多边形坐标。
- 官网 2015 年维护公告：同时列出伽蓝殿、月恒堂、梵音堂、云林图书馆等开放建筑；官网 2021 年水陆法会文章列出济公殿、伽蓝殿、客堂、十方苑、月恒堂等活动空间名称。

### 来自航拍图的视觉事实或推断

- 图中入口/出口位于画面下方，主轴建筑按近到远标注为天王殿、上香区、大雄宝殿、观音殿、药师殿、藏经阁、华严殿；这是图中标签和视线顺序，不能直接当作官方平面序列。
- “上香区”看起来是天王殿与大雄宝殿之间的开放前院/仪式空间，而不是一座建筑；红框和香炉图形更像场地标注。模型应优先把它表现为空院、香炉和通行空间，不增加一座“上香殿”。
- 航拍图中大雄宝殿背面到药师殿之间出现“观音殿”标签，可能指大雄宝殿后壁海岛观音、礼拜点或航拍标注者对局部空间的简称；在缺少官方独立建筑 polygon 前，不足以新增主轴单体。
- 航拍图的左右翼标签具有空间参考价值，但摄像机斜视、树冠遮挡和标签偏移会改变视觉位置；它们只能指导“哪一侧需要补建筑”，不能指导真实米制距离。

## 藏经阁、藏经楼、直指堂与观音的名称关系

官网丛林文章把法堂称为灵隐寺的“直指堂”，并写法堂与藏经楼的通常上下关系；官网交互导览图进一步把灵隐寺第四进直接解释为：顶层藏经楼、中层法堂、底层文物展厅。由此，现状建模最稳妥的语义是一个第四进建筑：`直指堂/法堂` 为建筑或功能体名称，`藏经楼` 为顶层功能，`文物展厅` 为底层功能。航拍图写“藏经阁”可以保留为游客视觉标签的异名，但不能据此再加一座独立的藏经阁。

“观音殿”需要单独处理。灵隐寺官网对大雄宝殿背壁海岛观音的描述非常具体，包括童子拜观音、地藏、观音踩鳌鱼和五十三参群雕；这与航拍图在大雄宝殿后方标出“观音殿”相邻，但没有证明那里有独立屋顶单体。官网另有法会文字使用“观音殿”这一礼拜点名称，但法会行程和仪式用名不能替代建筑总平面。当前建议把观音标注挂在大雄宝殿背面/后院场景，独立殿体保持 `unknown`，直到取得官方导览图该标签的弹窗内容、可核查航拍原图来源或建筑 polygon。

## 屋顶与形制核对

### 大雄宝殿

官网中文写“古代建筑单层三重歇山顶”，并列出七间×四间及 33.6 米。当前模型已经改为低两层环檐、顶部完整歇山屋顶和单层殿身；这对应“三重檐线”视觉要求。几何层数是屋面表达参数，不能被解释为三层楼或实测层高。

### 天王殿与药师殿

官方资料对天王殿给出入口位置和内部造像，没有本轮可复核的檐数/建筑高度；不应从航拍顶面像素推断。药师殿有官方“单层重檐歇山顶”和七间×三间，当前 model 的两层 roof profile 有依据，但出檐宽度、屋脊高和台基仍未知。

### 华严殿

官方资料支持其为轴线后端、地势最高建筑，并给出与法堂约 150 级台阶的相对高处关系；没有可靠的当前屋顶檐层、建筑层数和米制高度。现有单 roof profile 可以作为艺术化占位，不可宣称形制已核实。

### 五百罗汉堂

官方日文导览明确卍字形平面、双檐组合和反翘檐口，且位于大雄宝殿西侧。当前模型使用来源于 OSM 的凹形 21 点轮廓、6 段双檐屋顶，并且没有内天井；其各翼尺寸、中央铜殿外观和 25 米的测量基准仍不应从航拍比例推算。此前“9 个矩形部件”的描述属于复核前实现。

## 实施结果与仍有边界

1. **语义与标签已修正**：第四进显示为“直指堂／藏经楼”，并保留 OSM 原名与 `sourceName`/`semanticRole` 来源字段；大雄宝殿详情说明海岛观音群雕位于殿内后壁，没有新增独立观音建筑、造像或热点。
2. **上香院已实现**：天王殿与大雄宝殿之间表现为开放上香空间、小香炉、连续院落、平路和殿前短台阶；它不是建筑 footprint，也没有伪造 WGS84 polygon。
3. **侧翼已按来源落地**：云林图书馆、月恒堂、禅堂、伽蓝殿、客堂使用对应 OSM 命名对象；侧边艺术廊房已表现。十方苑、医务室、钟鼓楼没有可靠 footprint，未命名东翼仍未建，不能用未命名 way 强行命名。
4. **屋顶已按复核结果调整**：大雄为单层殿身、低两层环檐和顶部完整歇山屋顶；药师保持重檐；罗汉堂使用凹形 21 点轮廓、6 段双檐且无内天井。天王、华严的精确檐层仍待一手资料，不用航拍透视补猜。
5. **视角与标注已调整**：镜头按建筑包围盒自适应并正向中轴；景点名称使用白色文字、透明背景和单层轻微暗影。方向、距离与艺术化高度仍遵循来源边界，不从航拍像素测量米制值。
