# West Lake Implementation Plan

> **For agentic workers:** Execute the approved design in this session using the existing Vite and Three.js patterns.

**Goal:** 展示西湖与周边真实山体高程，并可切换黄山。

**Architecture:** 独立西湖 DEM、湖岸与场景模块；主入口按 URL 参数选择场景。共用样式与实时光照计算，不改黄山场景和数据。

**Tech Stack:** Vite、Three.js、SunCalc、Python Pillow、Copernicus GLO-30、OpenStreetMap。

- [x] 数据：新增 `scripts/generate-west-lake.py`，读取 `N30E120.tif` 和 OSM 数据，生成原始高程二进制、元数据、湖面掩膜、岸线和点位 JSON。保持 WGS84 和源 GeoTIFF 像素中心坐标一致，岛屿作为孔洞；断言轮廓闭合、点位在范围内、掩膜有水面。
- [x] 地形：新增 `src/west-lake-terrain.js`，按真实水平比例映射栅格，使用展示用垂直夸张，生成底座、平整的岸线多边形水面和岛屿孔洞。原始高程文件不做平整化修改。
- [x] 展示：新增 `src/west-lake-scene.js`，实现湖山全景、湖面、群山、俯瞰和山地点位，按杭州坐标计算实时光照，支持漫游、罗盘、纯模型和资源释放。
- [x] 入口：修改 `src/main.js`、`index.html`、`src/style.css` 增加黄山/西湖链接及西湖文案。`src/lighting.js` 增加可选经纬度参数，默认黄山行为保持一致。
- [x] 验证：运行生成脚本、与源 GeoTIFF 样本比对、`npm run build`；浏览器验收桌面与 390px 视口中的场景、所有视角、漫游和纯模型恢复，再回归黄山；记录数据范围、比例、来源与精度限制于 `README.md`。
