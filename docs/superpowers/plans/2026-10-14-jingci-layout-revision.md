# 净慈寺复建方案布局改造

用户选择以所提供的鸟瞰图重建整体布局。本次范围为本地模型和建筑名称调查，不发布网站。

1. 核对图像出处与名称资料 → 验证：找到同图原始项目页，并把现状建筑资料与复建效果图分开。
2. 按图扩展中轴、前院双侧小楼、后部高台大阁、两翼院落和山林 → 验证：实际几何的位置、高差、院落围合、简模/详模投影与树木避让检查。
3. 添加分区探索说明与逐栋对应清单 → 验证：已知名字有来源，无法定位的建筑使用分区名，不把候选写成真实殿名。
4. 检查西湖全景、单景进入/返回、桌面与手机视图 → 验证：项目测试和构建通过，浏览器实际检查并保存新布局截图。

## 已确认边界

- 用户图片与木建筑研究中心的「杭州净慈寺复建项目」第一张鸟瞰效果图匹配，第二张图为反向视图，可辅助判断围合关系。
- 该页未提供编号总平面或实测尺寸；建筑尺度、台地、道路、山坡按图艺术化复原。
- 殿名调查不能代替方案逐栋编号图。主轴、钟楼等名称与粗略关系可引用现状资料，未确认的侧院与后部高阁保留分区名称。
- 参考图仅保存于研究资料目录；不将未核实版权的设计方图片加入运行时配图库。
