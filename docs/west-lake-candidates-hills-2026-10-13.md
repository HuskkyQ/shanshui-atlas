# 西湖周边群山新增景点候选（2026-10-13）

## 调查范围与使用边界

本次调查只整理西湖西部、南部群山中的候选景点，不直接修改 Three.js 数据。项目当前模型范围约为 `120.055139–120.170972E, 30.166250–30.285972N`；候选点在实现前仍需分别核验 WGS84 坐标、入口、开放状态、景点边界和是否适合独立建模。本清单不把路线、村落或茶叶产区当成一个可以直接落点的建筑 POI，也不把同一景区的别名拆成多个重复点。

现有项目已经有灵隐寺、北高峰、灵顺寺、南高峰、五云山、龙井泉、九溪烟树、烟霞洞、葛岭、宝石山、玉皇山、紫来洞、福星观、抱朴道院、保俶塔，以及西湖湖面和三潭印月、雷峰塔等模型。本轮候选重点补充现有群山网络中缺少的寺院、茶园和山麓景观。

## 证据与空间关系

### 灵隐—天竺寺院组

杭州市文化广电旅游局的“城市·漫步”专题将“灵隐寺—永福寺—法镜寺—法喜寺”作为“佛国禅风”线路的一组景点，说明这些名称在官方旅游语境中是连续的寺院游览关系，但不是一个寺院建筑群。[杭州市文化广电旅游局《城市·漫步》](https://wgly.hangzhou.gov.cn/cw/cn/index.html)

官方旅游资料明确，天竺山有上、中、下三座寺院；上天竺即法喜寺，地址为天竺路239号，并介绍其观音文化和山地环境。[杭州市文化广电旅游局《Faxi Temple》](https://wgly.hangzhou.gov.cn/art/2021/9/14/art_1229495371_58938316.html)

官方旅游资料确认法净寺是“三天竺”中的中天竺，历史上曾为五山十刹之一，周边看点包括千岁岩、枫木坞。[杭州市文化广电旅游局《Fajing Temple》](https://wgly.hangzhou.gov.cn/art/2023/8/16/art_1229740543_58948406.html)

法镜寺在本轮检索中未找到同等稳定的官方独立景点页面，但官方旅游资料明确“上、中、下三天竺”这一组关系；另有浙江省官方旅游媒体介绍法镜寺位于莲花峰下、沿天竺溪与灵隐相接。该条只支持把法镜寺作为三天竺独立寺院候选，不支持直接填写模型坐标或当前开放状态。[浙江省官方旅游媒体《How to have a fulfilled day in Hangzhou》](https://www.inzhejiang.com.cn/Travel/attractions/201911/t20191126_10765109.shtml)

永福寺、韬光寺属于灵隐飞来峰景区语境中的独立寺院。杭州市民族宗教事务部门公开答复将灵隐寺、永福寺、韬光寺列为分别预约的寺院，支持产品上保持三个独立景点名称；项目已有灵隐寺模型，因此后续建模不能把永福寺或韬光寺并入灵隐寺院落。[杭州市民族宗教事务部门答复](https://yst.hangzhou.com.cn/question.php?question_id=201109112833)

### 五云山—云栖—茶园网络

杭州官方“新西湖十景”页面把云栖竹径、满陇桂雨、龙井问茶等列为新西湖十景，并分别给出云栖、满陇桂雨和龙井问茶的游览方向；这支持将云栖竹径、满觉陇·满陇桂雨和龙井茶园作为景区节点，但不能把满觉陇村、满陇桂雨公园和南高峰登山口当作同一位置，也不能把景区主题名直接当作建筑点。[韵味杭州《新西湖十景》](https://ywhz.hangzhou.com.cn/hssj/content/content_6219183.htm)

杭州文广旅游局发布的茶园漫步线路为“梅家坞茶文化村→十里琅珰→三分叉→狮峰→龙井村→中国茶叶博物馆”，说明梅家坞、十里琅珰、狮峰、龙井村之间是连续的游览路线；它没有提供本项目所需的 OSM way 几何或实时开放状态，后续仍需单独核验。[杭州文广旅游局《亚运时刻·最忆杭州》PDF](https://wgly.hangzhou.gov.cn/attach/538/2307051510367229.pdf)

西湖龙井茶管理协会发布的产区资料（来源注明为杭州西湖风景名胜区）说明“狮、龙、云、虎、梅”历史产区，现有传统产地包括龙井、翁家山、杨梅岭、满觉陇、梅家坞、灵隐、双峰、茅家埠、九溪、梵村等；这支持把狮峰/龙井与梅家坞理解为产区和景观组，而不是一个单独的“茶山点”。[西湖龙井茶管理协会《西湖龙井茶“狮、龙、云、虎、梅”字号的历史形成及地理分布》](https://www.xhlj.org.cn/page/3000/ch01/cat01_02/2024-04-08/17820270780848719.html)

杭州官方英文旅游资料介绍龙井御茶园位于狮峰山、龙井村，并列出老龙井、宋代广福庵遗址、九溪源、胡公亭、辩才塔和狮峰山等周边历史要素。这里的“狮峰山/狮峰茶园”和“龙井村”分别是山体茶园与村落空间，不能泛化为同一个点；可在产品上组成“龙井村·狮峰茶园”专题入口，但详情、坐标和后续模型应保留两者的地理差别。[杭州市政府英文站《Longjing Imperial Tea Garden》](https://www.ehangzhou.gov.cn/2018-08/15/c_271788.htm)

满觉陇桂花节的西湖官方报道将满陇桂雨公园定位在满觉陇一带，并说明其种植近四千株桂花、八十余个品种。该证据支持“满觉陇·满陇桂雨”作为首版区域入口，但满觉陇村、满陇桂雨公园和南高峰登山口分别属于村落、公园和入口实体，不能写成三个同址 POI；实现时应在组合入口下保留三个子点的地理差别。[西湖风景名胜区官方报道](https://westlake.hangzhou.gov.cn/art/2018/9/12/art_1639433_34208443.html)

关于五云山真际寺，现有项目候选资料已明确记录“五云山顶的真际寺与银杏”这一景点名称和山顶关系；当前未完成的是 WGS84 坐标、入口和开放状态核验，而不是景点是否存在。故本清单将它列为五云山的寺院子点候选，先不把未经坐标核验的点直接写入模型。

### 飞来峰造像

杭州市文化广电旅游局将灵隐景区定义为“灵隐寺和飞来峰”，并记载飞来峰又名灵鹫峰、山高168米，由石灰岩构成，沿岩洞和溪流峭壁分布五代、宋、元时期摩崖造像345尊。[杭州市文化广电旅游局《灵隐景区（灵隐禅踪）》](https://wgly.hangzhou.gov.cn/art/2023/12/1/art_1229734028_58951314.html)

因此，飞来峰造像应补为灵隐寺之外的独立景观/文保 POI。当前项目只有灵隐寺 POI，旧照片来源也不能替代 World 场景中的景观点。后续建模可以先做“飞来峰造像”组合节点（石峰、溪谷、洞窟和代表性龛像），待取得可用坐标和照片许可后再补精确子点；不应把345尊造像全部简化为一个寺院模型。

## 不应直接做成新增独立 POI 的对象

| 对象 | 正确表达 |
|---|---|
| 三天竺 | 作为寺院组/游览片区；法喜寺、法净寺、法镜寺是组内三个独立寺院，不能再额外放一个与建筑重叠的“三天竺景点”图标 |
| 十里琅珰 | 作为山脊徒步路线和区域，不是单栋建筑或单一山门；需要保留梅家坞、龙井、天竺、五云山、云栖等分支关系 |
| 龙井问茶 | 作为新西湖十景的主题名称；具体模型应区分龙井村、狮峰茶园、老龙井等经过坐标核验的子点，不能将村落和茶园泛化为同一点 |
| 满觉陇·满陇桂雨 | 首版可作为区域组合入口；满觉陇村、满陇桂雨公园和南高峰登山口分别保留村落、公园、入口属性与地理位置 |
| 五云山真际寺 | 作为已有五云山的寺院子点，除非后续取得独立坐标、入口和详情资料，否则不新增第二个五云山主点 |
| 梅家坞 | 作为村落/茶园区域点；“梅家坞上山口”另属于入口点，不能用村落中心代替入口 |

## 建议的下一步

1. 先做 P1 的数据核验和点位落图：永福寺、韬光寺、法喜寺、法净寺、法镜寺、云栖竹径、梅家坞、龙井村·狮峰茶园、满觉陇·满陇桂雨。
2. 三天竺先按“寺院组”组织 UI 数据，每座寺院保留独立详情和点击目标，但共享组级路线关系；不要把三座寺院做成一个重复图标。
3. 十里琅珰沿用已有路网调查结果，补路线节点和岔路关系，不生成虚构的路线端点。梅家坞、龙井、天竺、云栖和九溪应分别作为路线入口或景点区域。
4. 五云山真际寺与理安寺先保持 P2。真际寺的名称和“五云山顶”关系已有项目候选资料支持，下一步重点是补 WGS84 坐标、入口、图片来源和开放状态；理安寺仍需先取得稳定的一手景区或寺院资料。
5. 任何候选进入 `src` 前，先为每个点补齐来源、坐标置信度、景点类型（建筑/区域/路线/入口）和与现有 POI 的去重说明。
