# 西湖周边群山步道网络

调查与地图下载日期：2026-09-30。路线采用 OSM 的 WGS84 坐标，与既有湖岸和 DEM 一致。

原实现只从步道图中提取五条最短路径，山顶之后的步道和旁边的岔路没有导出，导致模型看起来像几条孤立的单线。现在保留彩色精选主线，并增加共享步道网络。旧主线停在山顶附近的节点仍有后续连接，不再被当作整条步道的尽头。

## 调查依据与覆盖

[杭州市体育局转载的登山活动推荐](https://ty.hangzhou.gov.cn/art/2020/1/2/art_1694286_41423254.html)支持北高峰至十里琅珰方向的连续关系；[都市快报 2025 年报道](https://mdaily.hangzhou.com.cn/dskb/2025/05/24/article_detail_2_20250524B021.html)和[杭州网登山攻略](https://hznews.hangzhou.com.cn/chengshi/content/2012-10/16/content_4427926_0.htm)说明了梅家坞、龙井、天竺、云栖、九溪的多级分支。三分叉是三向路口，五个主要入口分布在更大的路网中，不能据此画成一个五岔点。资料的节点关系与原始 OSM 几何分别核对，详细来源见[路网调查记录](west-lake-trail-network-research.md)。

当前提取 10,642 个 OSM 节点、10,798 条相邻边，合并成 1,004 段共享步道，地图折线总长约 186.5 公里。包含 524 个分叉节点、204 个普通道路接点和 113 个地图端点。这是按山间具名步道及其连接支路选取的地图网络，不代表景区公布的完整徒步线路。

| 独立路网 | 已核验的连接范围 |
| --- | --- |
| 宝石山、葛岭 | 保俶塔、抱朴道院周边步道与北山街接路处 |
| 湖西、湖西南群山 | 北高峰、南高峰、十里琅珰、万林背山、五云山；梅家坞、云栖竹径、九溪十八涧支路 |
| 玉皇山、凤凰山 | 两座山的连通登山步道 |

三个路网按真实地图节点保持独立。靠近但没有共享节点的路径没有补直线连接；地图中断也不等于现场一定是死路。当前数据不能单独证明黄龙洞入口已纳入共享路网，也没有逐段的实时开放信息。

## 提取与复现

数据保存在 `src/data/west-lake-hikes.json`。每段保留节点 ID、逐边 way ID、路名、highway、所属连通分量与端点类型。生成器合并 15 份 OSM XML，同一要素采用最新版本；输出按 DEM 范围裁剪。

共享网络以五条主线的精确边及具名山间步道为种子，在真实步行连接上扩展，到普通道路接点停止。普通道路只保留主线原先使用的精确节点对，不把整条道路当作种子。城区 pedestrian / cycleway 不做匿名扩展；新增 cycleway 必须明确允许步行。明确禁止访问或步行、地下隧道、建筑与室内路径被排除，索道和船线不进入步行网络。所有非步行 highway 均作为扩展边界。

按 JSON 的 `source.inputFiles` 下载 XML，保留原文件名，再运行：

```bash
python3 scripts/generate-west-lake-hikes.py /tmp/west-lake-terrain/*.osm
```

新增来源文件 `hills-northwest.osm` 和 `hills-ridge-gap.osm` 是生成器的必需输入，分别补齐西北山脊与中部衔接范围。缺失输入时脚本停止，避免悄悄恢复成不完整网络。

地图署名：© OpenStreetMap contributors，适用 [ODbL](https://www.openstreetmap.org/copyright)。原始 XML 保留在本地临时目录，不随构建发布。

## 展示与验证

“群山徒步”中，彩色带表示精选主线，浅色细线表示共享支路；浅色点表示分叉，金色点表示接路处，灰色点表示地图端点或展示边界。山顶附近的主线止点归为途经点，不误标为步道尽头。浅色网络合并为一次 LineSegments 绘制，节点合并为一次 Points 绘制，避免为每段创建独立绘制对象。沉浸模式保留路网与景点交互，“去除光影”沿用隐藏线路和标记的既有行为。

31 项自动测试与生产构建通过。独立原始 XML 检查覆盖全部 10,798 条边：节点连续性、坐标、禁止访问标签均无错误；524 个分叉均有至少三个真实连接方向，普通道路均对应主线精确边。重复生成结果字节一致。浏览器验收结果与预览图见项目 README。

地图和报道用于地形展示，不能判断每段步道当日开放、施工或现场通行情况；实际路线应以景区公告和现场指引为准。
