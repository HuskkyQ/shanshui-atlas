# 西湖群山徒步路网调查

调查日期：2026-09-30。本文只记录公开资料支持的路线关系，以及当前项目 OSM 数据需要核验的范围。报道中的节点链不等于精确 GPS 几何；活动路线和历史报道也不等于 2026-09-30 当日开放或可导航。

## 核心判断

此前 `src/data/west-lake-hikes.json` 的 5 条路线只是从 OSM 步道网络中挑出的展示段。每条路线只有一条 `points` 折线和一个起终点，没有共享边、交叉节点和支线，因此旧页面会呈现为几条有头没尾的单线。

后续核验应保留现有精选主线，同时补充共享路网和分叉节点。最终几何必须逐边来自 WGS84 OSM，不能根据报道节点之间的直线距离补线。

## 对当前项目的验收重点

现有文档和数据已经有 5 条 OSM 展示段，但需要重点核验以下事实是否在路网上体现：

1. `beigao` 是否能沿共享步道接入美人峰、龙门岭、石人亭、狮子笼、天门山、十里琅珰、棋盘山、龙井方向；不能继续把北高峰终点停在一个无出口的山顶步道点。
2. 三分叉是否是三向节点：梅家坞、龙井/天竺、五云山/云栖竹径。五个主要入口应分布在整个网络中，而不是挤到一个节点上。
3. 五云山是否同时存在向九溪和沿万林山背向上天竺的分支。
4. 是否能从 OSM 核验梵村—五云山—九溪—六和塔活动路线的连续边；不能用直线补齐缺口。
5. 南高峰是否能找到四向游步道对应的真实入口；报道只证明“有四个方向”，不提供四个入口的精确名称和坐标。
6. 玉皇山景点节点链以及玉皇山—凤凰山连接是否有连续 OSM way；没有几何证据时只能标为待核连接。
7. 宝石山可按岳庙管理处专家路线和黄龙洞专题环线核验入口、出口与回接关系；所有具体边仍需 OSM 核验。

## OSM 与实时开放边界

当前项目数据源声明为 OpenStreetMap contributors，下载日期 2026-09-30，坐标为 WGS84。后续核验应保留 OSM node、way ID、highway 和访问标签，按节点度数寻找候选分叉，再用上述来源进行语义核对。

本文没有发现能证明 2026-09-30 每一段步道实时开放、施工状态和安全状况的完整官方公告。因此页面不得把报道路线显示为实时导航结果；如未来展示开放状态，应另接景区公告或现场数据并标注更新时间。

## 最终 OSM 源数据核验

针对最终生成的共享网络，使用 `/tmp/check_west_network.py` 读取 `/tmp/west-lake-terrain/*.osm` 的 15 份原始 XML，并按最高 version 的 OSM node/way 回查每条边。结果如下：

- 10642 个网络节点、10798 条边、1004 条 segments、524 个 junction、3 个连通分量；
- 每条 segment 的相邻 node pair 均为对应 OSM way 的连续原始 `nd`：0 个错误；
- 网络坐标与最高 version OSM node 坐标一致：0 个偏差；
- 未发现 `access=no/private`、`foot=no/private`、地下/室内/建筑、ferry、aerialway 或 motorway 边：0 个违规；
- 普通道路边均能在旧 5 条路线中找到相同 node pair + way：0 个遗漏；
- 梅家坞、云栖、万林背山、九溪十八涧均位于 component 1，并可到达五云主干；北高峰和十里琅珰也在该主干分量；玉皇山与凤凰山同属 component 2；宝石山与北山街同属 component 0。

白堤保留为透明来源：`28538290` 的 pedestrian 边在 `baoshi-ge` 旧主线中精确出现 2 次，总长约 23 米，连接北山街节点后进入宝石山路线。这是旧主线已有的步行接入，不是城区道路扩展。

上述核验证明最终数据与原始 OSM 几何和访问标签一致，但不能证明景区完整官方路网，也不能证明 2026-09-30 的实时开放状态。原始数据中虽存在名为“黄龙洞”的 OSM way，当前共享 network 没有带“黄龙洞”名称的 segment，因此本文仍不能证明黄龙洞入口已经纳入网络几何。
