# 拙政园首版建模研究

研究日期：2026-10-05。用户已确认“中部园核心水景，逐步做精细”，本轮已实现主页独立入口、主池二岛、七处建筑和热点交互，仅在本地更新。下文保留范围比较及研究依据，已实施边界见文末。

## 已核实的空间与形制

| 对象 | 可用于建模的事实 | 来源 |
| --- | --- | --- |
| 中部园 | 全园分东、中、西部；中部以水景为核心，建筑沿水高低错落布置 | [官方总览](https://ylj.suzhou.gov.cn/szsylj/sjyc/201905/c1df393edc8745abb20e8a9bd5525782.shtml) |
| 中央水系 | 远香堂北面池水为主要中心；主池与水湾、水院相通，山岛和桥廊分隔水面 | [官方理水专题](https://ylj.suzhou.gov.cn/szsylj/ylys/201903/df5a3bf3bdbd49b0b787076f355b1074.shtml) |
| 二岛 | 中部确有二岛，两岛之间隔一水峡；岛上有落叶树、常绿树、竹丛及水边芦苇 | [理水专题](https://ylj.suzhou.gov.cn/szsylj/ylys/201903/df5a3bf3bdbd49b0b787076f355b1074.shtml)、[植物专题](https://ylj.suzhou.gov.cn/szsylj/ylwh/201903/d978d21439a549c88244479c92ffda86.shtml) |
| 远香堂 | 四面厅，周围檐廊；北面与雪香云蔚亭对景，东面与绣绮亭对景；临水平台是自然衔接的关键 | [官方建筑专题](https://ylj.suzhou.gov.cn/szsylj/ylys/201903/484421d38f504f5787a8f307925e3ad7.shtml) |
| 雪香云蔚亭 | 山上长方形亭，与远香堂形成南北对景 | 同上 |
| 荷风四面亭 | 六角形平面；是观看香洲、倚玉轩的水边视点 | 建筑专题、理水专题 |
| 香洲 | 临水旱船；前、中、后三段轮廓，尾舱楼层是识别特征；南侧有石板木栏小桥 | 建筑专题、理水专题 |
| 小飞虹 | 廊桥，具有分隔水面和增加景深的作用 | 理水专题 |
| 梧竹幽居 | 方亭，可西望园景；亭旁梧桐、竹是主题植物 | 建筑专题、理水专题、植物专题 |
| 见山楼 | 官方确认的中部主要景点；楼的外形与水面之间应保持合适的体量关系 | 官方总览、建筑专题 |

园林外观基调可依据建筑专题采用粉墙、黑灰瓦顶、栗壳色木构。屋顶类型、窗口、廊柱应按对象分别处理，避免所有建筑共用同一个亭子外形。

## 图纸和模型资料的边界

- [UNESCO 拙政园保护范围图](https://whc.unesco.org/document/104734)已经打开核验：包含园区边界、周边街道、北箭头和比例尺，属于保护范围图，不能用于确定全部内部景点位置。
- [苏州民族建筑学会《苏州古典园林营造录》](https://www.xiangshanbang.org.cn/uploads/file/20240304/gudianyuanlinyingzaolu.pdf)检索到拙政园部分平、立、剖面资料；本次工具未成功打开全文，后续需逐页核验适用建筑及图纸年代。
- [1993 年遥感研究 PDF](https://gtzyyg.com/cn/article/pdf/preview/10.6046/gtzyyg.1993.03.03.pdf)检索到园区解译图；本次全文获取失败，仅记录为待读线索，不能称为当前测绘数据。
- [2023 年园林设计论文](https://pdf.hanspub.org/Design20230300000_27103794.pdf)已读到其图 1 来源说明：平面图转载自网络检索，并非该论文原始测绘。该图不能因为论文标有 CC BY 4.0 就被直接视为已获许可的原始底图。
- 本轮尚未取得可直接接入的完整 GLB / glTF 模型，也未取得当前建筑的完整实测尺寸。公开文字资料可确认形制和部分对景，不能生成所有建筑的精确坐标。
- 两岛具体轮廓、各桥头连接点、院墙与廊的完整拓扑应继续与可信导览图、地图轮廓和实景交叉核对；不得用想象的直线游路冒充真实连通关系。
- 现有 30 米 DEM 适合山地，分辨率不足以表达园内池岸、台阶、假山和建筑基座；园林应采用局部平面与独立几何建模。

## 首版范围建议

推荐“中部园核心水景”：主池、二岛、自然石岸、必要桥廊，重点制作远香堂、雪香云蔚亭、荷风四面亭、香洲、小飞虹、梧竹幽居、见山楼七处建筑。先核对平面与连通关系，再深化屋顶、木构、门窗、栏杆及植物。

可选范围比较：

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 中部园核心水景（推荐） | 水景、岛山、厅堂、旱船、亭与廊桥类型齐全，适合近看与逐步打磨 | 东、西部后续分别增加 |
| 全园简化总览 | 首轮看到东、中、西三区 | 单体细节和可探索程度较低 |
| 远香堂与主池局部 | 最快建立一个精细小场景 | 园林游览的空间层次较少 |

## 接入现有项目的建议

原项目将黄山、西湖路由交给地形展示，详细景点注册表绑定西湖。拙政园位于苏州，因此采用主页独立园林卡片及单独动态加载入口 `/?place=zhuozheng-garden`，保留两个现有入口和收藏行为。

园林页面沿用旋转、缩放、Shift＋左键平移、沉浸开关、名称与图标同效点击、平滑热点镜头和返回主页。首版建议固定日间荷景，提供总览及七个建筑热点；详情附资料出处，照片只接入已确认复用权限的素材，未取得时提供明确空态。

此入口直接进入独立园林场景；既有西湖 World 与景点的飞行、双画布渐变及返回状态保持当前流程。需要改变资源加载的文件应保持最小范围，不扩展为全国地图系统。

## 首版验收建议

1. 水面、岛屿、岸线和桥廊不相互穿插，已建游路不存在人为断头；未核验连接不声称可通行。
2. 七处建筑具有可区分的轮廓，远香堂—雪香云蔚亭对景、香洲旱船和六角亭等已核实关系可读。
3. 桌面与手机总览及热点近景均可见，详情卡不遮住目标；名称不换行、有清晰点击反馈。
4. 首页入口、收藏、进入、返回和重复访问有效；动态资源与事件在退出时释放。
5. 跑现有相关测试及生产构建，并在浏览器核对画面和控制台；艺术化尺寸和未测绘边界如实说明。

## 本轮实现与后续边界

- 主池实际采用 OSM relation 7399712 的外环与两个 inner ring；不是用椭圆代替池岸。建筑 footprint 和道路由同一次局部 XML 提取、投影并裁剪，保留源坐标与对象 id。详见[局部布局来源](zhuozheng-layout-sources.md)。
- 七处建筑具有各自造型，山岛步道逐段贴地，池岸、乔木、竹和荷叶补充环境层次。建筑高度、台地、屋顶曲线、窗格及植物均为艺术近似，未复原整套院墙和长廊拓扑。
- 完成普通与沉浸模式、图标及名称同效点击、平滑镜头、返回主页、收藏持久化和手机布局；照片保留空态。
- 111 项自动测试与构建通过；保存桌面、近景、手机浏览器截图。后续可逐个建筑对照实景深化，再扩展院墙和长廊；东园、西园及殿堂内部不在本轮范围内。
