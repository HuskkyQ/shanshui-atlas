# 建筑模型

此目录用于集中存放可复用的独立建筑模型。每栋建筑使用一个子目录，按需保存程序化模型代码、建模工程文件、导出的 GLB/glTF 及相关贴图。

## 存放方式

例如 `src/models/hexagonal-pavilion/` 存放六角亭的模型。子目录使用小写英文与连字符命名，仅在实际制作模型时创建。

## 模型约定

- 使用米作为模型尺寸单位，基座中心为原点，地面高度为零。
- 项目使用的模型以 `+Y` 为上方、`+Z` 为入口方向；建模工具中的坐标轴在导出时转换。
- 模型只包含建筑自身，地图位置、朝向、场景比例和地形贴合由场景层处理。
- 周围山水、树木、道路、灯光和镜头由具体场景组合。

现有场景中的模型尚未迁移至此目录；新增模型可先采用以上约定。
